# Azahar YW Compatibility Fork v0.4.1

## 概要

v0.4.0への取り込みが漏れていた**マウスボタンのキー割り当て機能**を追加する、非公式の修正プレリリースです。既存のv0.4.0タグ・Releaseは変更しません。

## v0.4.0からの変更

- **マウスボタン入力:** Qt版Azaharの入力設定で、マウスの左・右・中・戻る・進むボタンをエミュレートする3DSボタンに割り当てられるようにしました。
- **タッチ操作との競合対策:** 左クリックのタッチスクリーン操作を維持し、割り当て済みマウスボタンとタッチ入力の優先関係を設定できるようにしました。押下中にカーソルを動かしても入力先が切り替わらないようにします。
- **入力状態の後始末:** ウィンドウの終了などで押下状態が残らないようにする処理を追加しました。
- **プロファイル・テスト:** 割り当てと優先設定を入力プロファイルに保存し、マウスボタンの押下・解放、タッチ優先処理、設定保存の回帰テストを追加しました。

実装は [PR #36](https://github.com/AlexanderGG-0520/azahar/pull/36) に由来します。v0.4.0ではこの変更がリリースブランチへ取り込まれていなかったため、今回の修正版に含めます。

## 対応環境と配布

- Windows MSYS2インストーラーおよびポータブルZIP
- macOS Universal ZIP
- Android arm64署名付きVanilla APK
- SHA256チェックサムファイル

マウスボタンのキー割り当て機能は**Qtデスクトップ版向け**であり、Android版で同じ設定UIやマウス動作を保証するものではありません。Android APKのアプリIDは引き続き `io.github.alexandergg0520.azaharyw`、versionNameは `yw-v0.4.1-vanilla`、versionCodeは `4001000` です。固定リリース鍵による署名を維持し、v0.4.0からの更新互換性を確保します。

## 検証と制限

リリース用のWindows・macOS・Androidビルド、署名、アセット検証、およびArchパッケージ検証は、公開Workflowの成功を条件とします。ソースのテスト追加はデスクトップ実機での全入力動作確認を意味しません。

マウスボタンの実環境での操作感、各種マウス・ウィンドウ管理環境との互換性、長時間ゲームプレイは個別の確認が必要です。AndroidのLevel256、Pretendo、CECDすれちがい通信、HOME復帰などは引き続きAndroid実機では未検証です。

起動前にセーブデータ・NAND・SDMCをバックアップしてください。ゲームROM、ファームウェア、暗号鍵、認証情報などは配布しません。本ソフトウェアはAzahar公式版とは別の非公式フォークです。
